# Contributing

Thanks for your interest in improving this project.

## Bug Reports

Include your OS, Python version, reproduction steps, and complete error message.

## Improvements

Useful contributions include CPU-friendly training improvements, embedding visualizations, contrastive-learning experiments, notebook explanations, and Django UI improvements.

## Pull Requests

1. Fork the repository.
2. Create a focused feature branch.
3. Test the notebook or web app.
4. Update `CHANGELOG.md` when appropriate.
5. Submit a clear pull request.

Please avoid adding unnecessary modules, preprocessing pipelines, or large generated files.
